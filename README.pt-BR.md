## 🚧 O que estou construindo

**Deployer Genérico** · Go, gRPC
Um deployer self-hosted para múltiplos servidores. Um control plane central se comunica com um agente leve em cada servidor por um stream gRPC bidirecional (sem precisar abrir portas de entrada) e funciona por reconciliação de estado desejado, o mesmo modelo usado pelo Kubernetes e pelo Nomad. Ele detecta a stack a partir do repositório e gera um Dockerfile multi-stage automaticamente.

**Gerenciador de Finanças Pessoais** · Go, Angular, PostgreSQL
Um app de finanças multiusuário que se conecta aos bancos pela Pluggy, importa holerites, acompanha metas de economia configuráveis e exporta um relatório completo em planilha. Cada usuário é totalmente isolado (Row Level Security, credenciais criptografadas).
