## 🚧 What I'm building

**Generic Deployer** · Go, gRPC
A self-hosted deployer for multiple servers. A central control plane talks to a lightweight agent on each server through a bidirectional gRPC stream (no inbound ports needed) and works by reconciling desired state, the same model used by Kubernetes and Nomad. It detects the stack from the repository and generates a multi-stage Dockerfile automatically.

**Personal Finance Manager** · Go, Angular, PostgreSQL
A multi-user finance app that connects to banks through Pluggy, imports payslips, tracks configurable savings goals and exports a full spreadsheet report. Each user is fully isolated (Row Level Security, encrypted credentials).
